# vaulttime

Vault numeric time values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/vaulttime/

## Install / run

```bash
git clone https://github.com/theworker02/vaulttime.git
cd vaulttime
node src/cli.js
node --test
```
